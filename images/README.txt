IMAGE FILES TO ADD
==================

Put your own photos in this /images folder using these exact filenames:

1. hero-satellite.jpg
   - Hero/background image.
   - Suggested ratio: 16:9 or wider.
   - Suggested: real satellite ground station, antenna, satellite, night Earth, etc.

2. 5g-ntn.jpg
   - Research card: 5G/6G & NTN.
   - Suggested ratio: around 16:9.

3. satellite.jpg
   - Research card: Satellite Communications.

4. ml-data.jpg
   - Research card: machine learning / data.
   - A REAL photo of code, data visualization, lab monitor, etc. works well.

5. digital-twin.jpg
   - Research card: Digital Twin & ISAC.
   - Real industrial / robotics / lab image works well.

6. coco-nails.jpg
   - Use a real photo from The Coco Nails.
   - Suggested horizontal image, ideally 16:9.

The website still works if these files are missing:
dark-blue fallback blocks will be displayed instead.
